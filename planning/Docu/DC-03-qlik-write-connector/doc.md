# Qlik Write Connector

## Subject

The sole write target in v1: how data products are created and updated in Qlik Cloud, and everything the connector refuses to do.

## Scope

**In:** OAuth2 M2M auth, the capability manifest, reading data products and dataset items, resolving dataset members and owner emails, create, replace-only JSON Patch update with ETag concurrency, the lifecycle actions behind their opt-in, and the tenant-unverified registry.

**Out:** The Qlik glossary write path (Track B, RM-05), any reverse flow, and access control.

- `packages/qlabs-connector-qlik/`
