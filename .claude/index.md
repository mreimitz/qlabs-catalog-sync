# Claude Controls

## Commands

* [New research](commands/new-research.md) - Scope and transactionally create an OKF research topic.
* [New roadmap item](commands/new-roadmap.md) - Create a validated roadmap item.
* [Research status](commands/research-status.md) - Show current RS and RM lifecycle states.
* [Validate OKF](commands/validate-okf.md) - Validate official and strict-profile conformance.
* [Synchronize OKF](commands/sync-okf.md) - Regenerate managed indexes and the master roadmap.

## Skills

* [Research intake](skills/research-intake/SKILL.md) - Turn a research request into a complete topic contract.
* [Research intake questions](skills/research-intake/questions.md) - Editable intake question set.

## Profile and tooling

The machine-readable profile is [`okf-profile.json`](okf-profile.json), and the dependency-free
CLI is [`scripts/okf.py`](scripts/okf.py).
